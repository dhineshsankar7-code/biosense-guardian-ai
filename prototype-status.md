# Prototype Status

**Stage:** Interactive software proof of concept.

**Implemented:** Browser-based dashboard, simulated vital readings, trend visualization, basic illustrative threshold labels, event log, and alert-preview button.

**Not implemented:** Physical wearable, real sensor integration, validated readings, backend/cloud storage, user accounts, caregiver messaging, emergency-service integration, clinical validation, or AI-based prediction.

**Evidence to collect next:** photographs of the physical prototype if built; sensor test logs; comparisons with appropriate reference equipment; screenshots of the working app; usability feedback gathered with consent; and a record of bugs and improvements. Clearly label simulated data and do not claim unperformed tests.
